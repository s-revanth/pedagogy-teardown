# Isolation - Mind Field Ep 1 (Vsauce, 34:45)

## Arc
Hook (imagine the room) -> boredom theory (Plutchik wheel, 1:30) -> stooge experiment: shock vs boredom (2:23-5:51) -> sensory deprivation history and a float-tank trial run (6:14-9:28) -> prior cases: Follini, solitary confinement (9:28-14:03) -> setup, baseline vitals and expert predictions (14:03-17:05) -> 72 hours in day-by-day check-ins (17:26-29:51) -> post-tests -> reunion and moral -> trailer (admin).

## Strongest moves
1. **Stooge experiment (2:23-5:51).** Jamison states "never again", then presses the shock button after 1:57. The hypothesis is demonstrated before it is named, then confirmed by interview. This is act-it-out plus learner discovery for the viewer.
2. **Stepping-stone trial (7:05-9:28).** A one-hour float with Dominic Monaghan calibrates expectations and raises dread for the real test; Dominic's "unhappy about what's coming up" ties it forward.
3. **Visible repetition of time guesses (18:36, 20:04, 22:23, 23:15).** Each guess is wrong in a bigger way, so "circadian cues vanish" is felt, not asserted. Experts annotate: hunger and sleep stop working as clocks.
4. **Live expert commentary (15:12 onward).** Predictions first (jet lag, neurotic amplification), then reactions. It tests hypotheses on camera, including surprise when post-tests improved (30:58, adrenaline explanation).
5. **Reframed proverb (32:38-33:10).** The only abstract idea arrives last: experience is complete only when shared. It reads as earned because the viewer has watched his need for people grow.
