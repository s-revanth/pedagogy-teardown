# The Secret Reason Horses Let Us Ride Them (CGP Grey, 5:35)

## Structure arc
Familiar object (fluffy sheep, 0:00) -> definition of domestication -> question (why so few?, 0:16) -> build a checklist one criterion at a time: Feedable (0:21), Friendly (1:03), Fecund (1:52), fast growth / taming distinction (2:10-3:18), Family (3:26) -> alliterative recap (5:11). The title question (horses vs zebras) is held back as the last criterion's showcase.

## Strongest moves
1. **Contrast pairs.** Each criterion is taught with near-twins where one passes and one fails: cow/tiger (0:21), pig/elephant (2:40), horse/zebra (3:26), dog/cat (4:31). Holding everything else constant makes the causal trait visible.
2. **Mechanism analogy then number (0:21-0:48).** A cow is a grass-to-steak machine, a tiger a steak-to-tiger machine; then the 10:1 ratio and "thermodynamics". A playful frame moves to a real causal law in about 25 seconds.
3. **Minimal definition then refine.** Domestication is defined at 0:00, then sharpened against taming at 2:10 and compressed to a rule of thumb at 3:18 (farm vs circus).
4. **Surface-similarity misconception (3:53-5:11).** Zebras look like horses but lack herd hierarchy. Closing line: horses on the outside, not on the inside.
5. **Mnemonic rule list (5:11).** Friendly, Feedable, Fecund, Family; must pass all, which explains the "baker's dozen".

## What is unusual
Humor carries almost every beat (hippo murder high-score, panda breeding, war bears), and each joke is attached to the criterion being taught, so it works as a memory hook rather than filler. The criteria order is explicitly argued (0:48 "pig before the pen"), a rare case of saying the dependency order out loud. The plant aside (2:26) generalizes the concept outward mid-video.

## Principle verdicts (brief)
Confirmed: 1, 3 (F-labels as interface), 4, 9, 11, 12, 13. Partly: 5 (gazelle chase), 7, 10. Not observed: 2, 6, 8 (pace is uniformly dense, with no visible slowdown). Skeptical note: the checklist is presented as settled; there is no honest caveat about contested cases.

## Velocity implications
- Scene: a grid of animals x criteria that fills with ticks and crosses as each pair is discussed.
- Orchestrator: for classification lessons, choose contrast pairs differing only in the target trait.
- Voice: close subtle distinctions with a one-line heuristic.
- Learner model: test for surface-similarity misconceptions before revealing the hidden trait.
- Eval: each criterion needs at least one passing and one failing example.
