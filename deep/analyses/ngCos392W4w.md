# Reducible: 5 Simple Steps for Solving Any Recursive Problem (ngCos392W4w)

## Arc
Hook is a promise rather than a puzzle: recursion feels confusing, here are five steps (0:00). Then one fixed ritual is run on three problems of rising difficulty: sum to n (1:07), grid paths (6:15), integer partitions (11:07). Each run goes simplest input, examples, relate large to small, generalize, code. A recap restates the steps (19:56). Notation and code come last every time; the code is treated as nearly an afterthought.

## Strongest moves
1. **Pause-and-spot (2:19, 8:23, 14:16).** Before stating a relation, the video asks the viewer to find it, then narrows to three examples as a hint. Discovery is staged, with the hint as a fallback.
2. **Examples as a designed sweep (8:10, 13:46).** The narrator says outright that examples should sit next to each other, because the goal is relating each case to a simpler one. This is a reason for the tool, not just a rule.
3. **Pattern, then 'is it coincidence?' (9:20, 17:27).** A found relation is tested by building a bigger unseen case from it: 3x4 grid, then (9,5) with 5 + 18 = 23. The viewer sees the pattern survive.
4. **Honest base-case revision (7:56, 19:15).** Base cases are said to be revisable; the partition problem forces a negative-n base case after the recurrence appears.
5. **Bijection as explanation (8:37, 17:00).** The recurrence is justified by constructing paths or partitions, not by algebra.

## Unusual
Almost no analogy; the leap of faith (5:19) is the lone one. The humor is light ("sorcery", 15:11). It teaches a method by repetition across problems, not a single insight, and admits the third problem looks intimidating (12:15).

## Velocity implications
- Surface a visible numbered playbook and rerun it across problems.
