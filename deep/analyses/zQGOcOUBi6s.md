# The Immune System Explained I (kurzgesagt, 7:49)

**Arc.** Hook: you are under attack, defended by an army (0:00). A set-up block (0:17-0:52) lays out the full system: 12 jobs, 21 cells, 2 protein forces, a colour code, an interaction map. Then a single story, a rusty-nail cut (1:12), is told in time order: bacteria, macrophages, neutrophils, dendritic cell, T cells, B cells, antibodies, cleanup, memory. It ends by admitting how simplified this was.

**Strongest moves**
1. **Show full complexity, then filter (0:17-0:52).** The narrator reveals everything, then says only these cells will appear. The viewer knows the cast is bigger and trusts the subset.
2. **Colour-coded cells (0:35).** One interface (centre colour main job, ring secondary) is built once and could be reused every time a cell appears. It cuts the cost of each new cell symbol.
3. **Chronology as dependency order (1:12-5:41).** The dendritic cell shows up when macrophages and neutrophils are not enough, so each new actor has a reason to exist.
4. **Role analogies with failure modes.** Neutrophils kill friends and self-destruct after five days (2:22). Helper T cells tell exhausted factories not to die yet (4:12). The analogies explain regulation, not just function.
5. **Honest close (5:59).** It calls itself a very simplified explanation, then turns the complexity into awe.

**Unusual.** It does not start small; it starts with maximum complexity. There are no questions to the viewer and no brute-force pass. Named entities arrive at roughly one per 15 s, which is dense.

**Principle verdicts.** 1, 4, 5, 11 confirmed. 10 contradicted (no tiny-to-bigger). 8 contradicted-ish: the idea rate stays high. 2 partly: the colour system helps but name load is heavy. 3, 7, 12 not observed.

**Velocity implications**
- Many-actor topics: render the whole cast once, colour-code roles, then spotlight per scene.
- Introduce each named entity at the moment it acts in the time-ordered story.
- Throttle names per minute in the learner model; this video would overload a novice.
- Close with an explicit list of what was left out.
