## Arc
Hook: genes as gamblers whose copies cannot see each other (0:00). A warning that Hamilton's rule deceived the presenter, plus a challenge to spot the error (1:05). Dice game and expected value (1:50-3:45). Blob forest with alarm-call altruism (4:15-7:30). Sexual reproduction and identical-by-descent (9:20-12:10). Stalemate shown (13:15), reveal (14:24), frequency framing (15:25), r derived (16:50), verified fix at 95% death (18:15), open-questions list and teaser (19:20).

## Strongest moves
1. **Planted-error challenge (1:05, 13:15, 14:24).** The presenter commits to a plausible expected-value model and tells the viewer a flaw is coming. When the sim stalls, he concedes the prediction was wrong.
2. **Brute-force dice first (1:50-2:44).** All six outcomes are enumerated before the average is named expected value. The same tool is reused for each sim, so it feels familiar when it breaks.
3. **Stepping notation (3:45, 14:57-17:40).** Only b, p, c appear first; r waits until the stalemate motivates it and is explained by splitting the group into non-identical and identical-by-descent parts.
4. **Seek disconfirmation (7:30).** Thirty runs of the sim are used to try to disprove the result.
5. **Verify the fix (18:15).** The new rule predicts exactly zero for the stalemate, then a small parameter change (95%) tests a case that should win.

## Unusual
The tutor-presenter models being wrong and says so, and lists untested cases at the end rather than claiming closure. The partial derivation is openly skipped (16:50).

## Velocity implications
- Add a planted-error playbook: the tutor commits to a naive model, flags a trap, and lets the sim refute it.
- Default verification visual: multi-run ensemble with thin lines and a thick average.
- Learner model: log the learner's commitment before reveal and score whether the flaw was spotted.
- Voice: model honest admissions of being wrong.
- Evals: confirm new notation appears only after a failure motivates it.
