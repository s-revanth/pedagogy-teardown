New theories

Failure-gated vocabulary

Teach a term after the failure it repairs. If so, learners recall its purpose more and re-ask less.

Memory 11:13; Neural net 5:48

Equation as label

Reveal formula after behaviour works, check with a special case. If so, symbol errors drop.

Fluids 11:07; Neural net 26:15

Fixed test choreography

Same inputs on every variant. If so, learners spot regressions faster.

Computers 7:56; Chess 15:45

Honesty as pacing

Flag your own uncertainty at the hardest beat. If resolved next, novices stay through it.

Memory 4:19; Fluids 8:42

Scaffolding removal

Rerun with labels hidden. If so, learners predict next step better.

A* 6:01; Computers 10:39

One knob, one cause

One adjustable parameter per concept. If so, learners predict unseen settings.

Fluids 35:53; Geography 28:16
