New theories

Agency before mechanism

Give processes goals (hunt, archive, hijack). CRISPR 4:19, Phage 1:37. If told passively, step recall drops.

Name the paradox late

Build the case, then name the contradiction. Information Paradox 4:15, Largest Star 4:31. If named at 0:00, engagement falls.

Trap at peak pattern

Break the rule after it is confirmed repeatedly. Largest Star 4:31, Largest Black Hole 6:29.

Fears retired by benchmarks

Return to each fear with a real event. Marianas 3:52, All Bombs 1:32.

Stakes before advice

Causal chain first, action last. Coronavirus 5:15-6:47, CRISPR 14:50.

Escalate on one template

Same sequence, bigger magnitude. All Bombs 2:27 then 4:40.
